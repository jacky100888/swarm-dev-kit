> **Swarm Stage 2（Claude 技術文檔與規格設計）**：本命令由 Claude 架構師（推薦 `claude-opus-5-5[1m]`）執行，為後續開發（Stage 3）與驗收（Stage 4）建立唯一真實規格契約。

根據參數選擇設計模式：

- `/design doc [功能]` → 生成完整技術規格文檔並寫入 `docs/specs/<feature>.spec.md`
- `/design checklist [功能]` → 生成設計品質與邊界檢查清單
- `/design [功能]` → 預設生成技術規格文檔（同 doc）

參數值：「$ARGUMENTS」

## 模式 1：doc（預設 — Swarm Stage 2 標準規格書）

### 二、核心設計原則

1. **契約優先**：前後端嚴格遵循專案既有統一成功回應包裝與分頁結構，禁止前端臨時容錯掩蓋後端失配。
2. **最小改動與複用**：優先複用既有工具函式與中介層。
3. **行數預算控制**：單檔行數嚴格控制在硬限制內（Java ≤ 300 / Go ≤ 400 / Vue·TSX ≤ 200 / TS·JS·Python ≤ 300）。
